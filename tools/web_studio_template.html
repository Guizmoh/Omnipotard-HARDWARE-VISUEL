Ce que la machine entend

tempo—
coups—
duree—
paroxysmes—

Les pads s'allument sur les vrais coups : grave → grosse caisse, medium → caisse claire, aigu → charley. La bande de 16 pas se cale sur le tempo detecte, l'image respire a chaque kick, et les glitchs ne tombent que sur les paroxysmes — les instants ou le morceau repart en force apres une respiration.

Morceau

Deposer un fichier mp3, wav, flac, m4a… ou cliquer

Votre morceau ne quitte pas le navigateur : tout est decode, analyse et dessine sur cette machine.

Couleur du trait

Fond

Le trait est additif : un fond clair mange son contraste. Le degagement creuse la texture derriere la machine pour qu'elle ressorte quand meme.

Enregistrer une video

L'enregistrement se fait en temps reel : il dure aussi longtemps que le morceau, et joue le son pendant ce temps-la. Surveillez le compteur d'images par seconde pendant la lecture : s'il tombe sous 25, descendez d'un cran de definition.

Le trace de la machine est exporte du moteur Python du projet, pas redessine : c'est le meme dessin que les rendus hors-ligne. Pour les rendus longs, en 4K, ou en lot, tools/studio.py fait le meme travail sans limite de duree.
